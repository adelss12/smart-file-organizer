# منظّم الملفات الذكي وكاشف المكررات (Smart File Organizer)

برنامج ويندوز عربي يفحص مجلداً، ويكتشف الملفات المكررة بدقة، وينظّم الملفات الفريدة في مجلد جديد مع الحفاظ على ترتيب المجلدات.

## ⬇️ التنزيل

### [تنزيل أحدث إصدار SmartFileOrganizer.exe](https://github.com/adelss12/smart-file-organizer/releases/latest)

ملف واحد يعمل مباشرة على ويندوز، دون تثبيت Python أو أي برنامج آخر.

> قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً. اضغط **More info** ثم **Run anyway**.

---

## 🛡️ الأمان أولاً (الإصدار 2.1)

- **معاينة قبل التنفيذ:** يفحص البرنامج أولاً ويعرض ما سيحدث بالتفصيل، ولا يلمس أي ملف حتى تضغط «تنفيذ».
- **لا حذف نهائي أبداً:** في وضع النقل تذهب المكررات إلى **سلة المحذوفات** ويمكن استرجاعها. على الفلاش ومجلدات الشبكة (التي لا سلة لها) تُنقل إلى مجلد `_مكررات_للمراجعة` داخل مجلد الإخراج.
- **حماية الأصل:** لا يُزال أي مكرر إلا بعد التأكد من حفظ نسخته الأصلية في المجلد الجديد.
- **تجاهل ملفات النظام** مثل `desktop.ini` و`Thumbs.db` وملفات أوفيس المؤقتة، و**الملفات الفارغة**؛ لأنها متطابقة دائماً وليست تكراراً حقيقياً.
- **تقرير صادق:** يذكر كل خطأ وسببه، ولا يقول «اكتمل بلا أخطاء» إلا إذا كان كذلك فعلاً.
- **زر إيقاف** في أي لحظة.

## 🌟 المميزات

- **كشف دقيق للمكررات** على ثلاث مراحل: الحجم ← بصمة أول 64KB ← بصمة SHA-256 كاملة.
- **يحتفظ بالنسخة الأقدم** من كل ملف مكرر (الأرجح أنها الأصل).
- **وضعان للمعالجة:**
  - **نسخ آمن:** ينسخ الملفات الفريدة إلى المجلد الجديد، ولا يلمس أي ملف في مكانه.
  - **نقل:** ينقل الملفات الفريدة، ويرسل المكررات إلى سلة المحذوفات، ويزيل المجلدات التي أصبحت فارغة.
- **لا يدخل مجلد الإخراج** أثناء الفحص (لا تكرار ذاتي).
- **حل تعارض الأسماء** تلقائياً (`ملف_v1`) دون الكتابة فوق أي ملف.
- **تقرير عربي** `تقرير_تنظيم_الملفات.txt` داخل مجلد الإخراج: الملخص، وكل مكرر مع أصله، وكل خطأ.
- **واجهة لا تتجمد** حتى مع المجلدات الكبيرة.

## 🚀 التشغيل من الكود

يحتاج Python 3 فقط (مكتبة Tkinter مضمّنة مع Python في ويندوز):

```bash
python organizer_gui.py
```

## 🛠️ بناء ملف EXE

يُبنى الملف تلقائياً على خوادم GitHub كلما تغيّر كود البرنامج، باسم رقم الإصدار المكتوب في `APP_VERSION` (ملف `.github/workflows/build-exe.yml`). للبناء يدوياً على ويندوز:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name SmartFileOrganizer organizer_gui.py
```
